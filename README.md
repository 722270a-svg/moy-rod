# Мой род — комплект для GitHub Pages

Это **не полная копия приложения**: сюда нужно добавить файлы последней версии «Мой род», включая `index.html`, `full_tree.html` и каталоги изображений/данных.

## Публикация
1. Создайте публичный репозиторий `moy-rod` под учётной записью `722270a-svg` на https://github.com/new.
2. Добавьте **содержимое** последнего архива приложения в корень репозитория. Файл `index.html` должен оказаться в корне.
3. Добавьте файл `.github/workflows/pages.yml` из этого комплекта (либо загрузите содержимое всей этой папки поверх файлов приложения).
4. Settings → Pages → Source: **GitHub Actions**.
5. После успешного workflow сайт будет доступен на `https://722270a-svg.github.io/moy-rod/`.

Осторожно: публичный репозиторий и Pages делают опубликованные ФИО, даты и фотографии доступными всем. Не выкладывайте исходный CDR, оригиналы фотографий, личные контакты и данные несовершеннолетних без необходимых разрешений.

Хранение добавленных через браузер данных остаётся локальным, если отдельно не реализована серверная база и аутентификация.
